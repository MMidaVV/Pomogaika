# Роли коротко

Три текста для команды. Полные версии: [бэкенд](backend.md), [ML / LLM](ml-llm.md), [фронтенд](frontend.md). План срезов: [PLAN.md](../PLAN.md).

## Бэкенд

Главная роль с первого коммита. Без этого ядра остальные не на чем стоять.

- Делает одно ядро, не «три чат-бота»: события, политики, брони, каналы, задачи, замок.
- Мультитенантность сразу: у каждой сущности есть собственник и объект.
- Брони без LLM: письмо Авито за секунды, iCal как сверка. Не обещаем календарь «в ту же секунду».
- Политики как код: что можно само, что с подтверждением, что никогда. Отмену брони и возврат система не делает.
- Бот собственника: новая бронь, конфликт с оценкой «что дешевле отменить», кнопки человеку, «закрой 10–12 мая».
- Дальше по срезам: гостевой канал, FSM клинера, адаптер замка. Если у замка нет API — ручной контур, ядро не стопорится.
- Не делает в фазе 1: веб-панель, MAX, биллинг, витрины, автоцены, оплату клинерам.

## ML / LLM

Нужен со среза гостевого копайлота и с фото клинера. На календарь и почту можно не ждать.

- Пишет и понимает текст. Сравнивает фото клинера с эталоном того же ракурса.
- Гость в копайлоте: черновик собственнику — отправить / поправить / ответить самому. Деньги и спор сразу человеку, без обещаний.
- Класс вопроса решает, можно ли когда-нибудь автопилот. «Модель уверена» — не повод слать самому.
- Фото: нет полотенец, лишнее, перестановка. Не вердикт «грязно» и не штраф. Пыль, запах, волосы модель не видит — так и говорим в продукте.
- Провайдер за абстракцией. Эталонные диалоги фазы 0 — регресс при смене модели.
- Не выдаёт коды, не отменяет брони, не ставит цену, не ходит в личные аккаунты, не распознаёт лица.

## Фронтенд

Не классический SPA в фазе 1. Основной интерфейс — Telegram.

- Сначала Mini App для клинера: 8–12 ракурсов, рядом эталон, «пересними это», уложиться в 5 минут на отчёт.
- Тон диспетчера, не проверяющего. На любой флаг — «не согласен».
- Веб-панель только в фазе 3, на том же API: календарь, объекты, журнал «что сделал бот и кто разрешил», отчёты. Telegram остаётся пультом.
- Своя витрина объекта — ещё позже.
- Не рисует админку «на всякий случай» в фазе 1, не делает камеры внутри квартиры и не показывает умный прайс как чёрный ящик.

# ML / LLM-инженер

Нужен со среза гостевого копайлота и с фото клинера. На календарь и почту можно не ждать.

- Пишет и понимает текст. Сравнивает фото клинера с эталоном того же ракурса.
- Гость в копайлоте: черновик собственнику — отправить / поправить / ответить самому. Деньги и спор сразу человеку, без обещаний.
- Класс вопроса решает, можно ли когда-нибудь автопилот. «Модель уверена» — не повод слать самому.
- Фото: нет полотенец, лишнее, перестановка. Не вердикт «грязно» и не штраф. Пыль, запах, волосы модель не видит — так и говорим в продукте.
- Провайдер за абстракцией. Эталонные диалоги фазы 0 — регресс при смене модели.
- Не выдаёт коды, не отменяет брони, не ставит цену, не ходит в личные аккаунты, не распознаёт лица.

Короткая сводка всех ролей: [README.md](README.md). Ниже — полный текст, его можно слать кандидату.

## Продукт

Pomogaika отвечает гостям и помогает собственнику в Telegram. Это не «чатбот с промптом». Деньги, календарь, коды от двери и задачи клинеру считает **обычный код**. Модель работает на границе: понимает текст, пишет текст, сравнивает фото с эталоном.

Если хочется агента, который сам бронирует, отменяет и штрафует — это не сюда. Архитектура: [architecture.md](../architecture.md) §3.4. Контроль клинера: [contractors.md](../contractors.md).

## Когда вы нужны

- **Фаза 0:** помочь разметить корпус вопросов (typical / money / conflict / other) и собрать эталонные диалоги. Это будущий регресс.
- **Фаза 1, срез 2:** гостевой копайлот. Без вас срез 1 (календарь и почта) всё равно едет.
- **Фаза 1, срез 3:** зрение для фото-чек-листа. Не блокирует выдачу задачи клинеру.
- **До фазы знакомых:** стратегия ПДн (токены вместо имени/телефона или российский провайдер для сырых текстов).

На старте это может быть один человек не на полный день. Отдельная ML-команда не нужна.

## Что делаете вы

**Текст (высокая доля LLM у роли «гость»):**

- Цикл: сообщение → контекст (роль, объект, бронь, knowledge, история) → модель с tool use → ответ. Инструменты вызывает бэкенд и гоняет через `Policy.check`. Вы не обходите политики промптом.
- Копайлот: черновик собственнику с кнопками «отправить / править / ответить самому». Автопилот — по классу вопроса и статистике подтверждений, не «модель уверена».
- Классификация вопроса: typical / money / conflict / other. Деньги и спор — сразу человек, без обещаний.
- База знаний — структурированные поля + FAQ в данных. RAG не заменяет анкету объекта. Промпт не содержит пароль Wi-Fi и код двери дольше, чем нужно.
- Абстракция провайдера: смена Claude / OpenAI / YandexGPT / GigaChat — конфиг. Трассировка каждого вызова.

**Зрение (клинер):**

- Сравнение кадра с эталоном того же ракурса: нет предмета, лишнее, перестановка, крупное «заправлено / пусто».
- Не вердикт «грязно» и не основание для штрафа. Пыль, волосы, запах, «сменили ли бельё» модель не видит — так и пишем в продукт.
- Ответ с уверенностью: высокая и простое исправление — одна фраза клинеру; средняя — флаг человеку; низкая — в статистику, клинеру молчим.
- Антифрод съёмки: не принимать вчерашнее фото как сегодняшнее (хеш, время Mini App). Не распознаём лица.

**Качество:**

- Регресс на эталонных диалогах фазы 0 при смене модели или промпта.
- Метрики: доля вопросов без человека, правки собственника, ложные эскалации, ложные флаги по фото, время клинера на отчёт (цель до 5 минут).

Роль подрядчика в тексте — низкая доля LLM: свободная фраза «приду через час» → перенос задачи, не чат-агент.

## Чего не делаете вы

- Не решаете, выдавать ли код, закрывать ли даты, отменять ли бронь, обещать ли возврат. Это политики и конечные автоматы.
- Не ставите цену. Формула цены детерминированная; вы позже можете объяснить её словами. Не парсите выдачу площадок «как умеем».
- Не делаете computer use, не читаем экраны мессенджеров, не пишем юзерботов.
- Не распознаём лица и не анализируем звук разговоров. Датчик шума — уровень, без записи.
- Не штрафуем клинера по выходу модели. Система — свидетель: факты расходятся → человек.
- Не кладёте персональные данные гостей в зарубежный API без согласованной схемы (токены / РФ-провайдер / гибрид).

## Стек

- Нативный tool use выбранного провайдера, не самодельный «JSON в конце ответа» как основной путь.
- Эвалы: набор диалогов в репозитории, прогон в CI или по кнопке до смены модели на пилоте.
- Бэкенд отдаёт вам контекст и инструменты, вы не ходите в базу в обход домена.

## Как поймём, что получилось

- На типовых вопросах пилота черновик можно слать почти без правок; на деньгах модель молчит и эскалирует.
- Смена провайдера не требует переписывать продукт.
- На фото клинера модель находит «нет полотенец» и не орёт «грязно» на блеск плитки.
- Есть цифры: что нашли, что пропустили, что придумали — на 20 уборках пилота, пока чек-лист не зафиксирован.

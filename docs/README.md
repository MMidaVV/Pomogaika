# Pomogaika

ИИ-диспетчер для собственников 1–10 объектов посуточной аренды. Заменяет «помогайку»: общение с гостями, календари по всем площадкам, задачи подрядчикам, датчики объекта, отчёты собственнику в Telegram.

Документы для обсуждения:

- Роли в команду, коротко: [roles/README.md](roles/README.md). Подробно: [фронтенд](roles/frontend.md), [бэкенд](roles/backend.md), [ML / LLM](roles/ml-llm.md).

- [Описание продукта](product.md) — что делаем, для кого, приоритеты, экономика, дорожная карта, риски.
- [Подрядчики: контроль без перегиба](docs/contractors.md) — клинеры и мастера: что модели видят по фото, что хорошо и что плохо в контроле, уровни доверия, реализация. Та же версия в [PDF](docs/Pomogaika-contractors.pdf).
- [Витрины и цена](docs/listings-and-pricing.md) — объявления на площадках, выбор площадок, ранжирование, слои формулы цены, стратегии-пресеты, порядок внедрения.

# Pomogaika — пилот KaVa

ИИ-диспетчер для апартаментов в Зеленоградске. Первый срез, чтобы **завтра показать**: копайлот по живым вопросам гостей, календарь на четырёх площадках, конфликт броней, задача клинеру.

Объект: ул. Гагарина, 87, кв. 19. Объявления: Авито, Суточно, Островок, Яндекс Путешествия.

Реальные пароли, коды калитки и телефоны из `dialogs/` в код **не попали**. Коды в демо — учебные.

## Где это живёт

Прод: https://pomogaika.vddapp.ru — вход через мини-приложение в Telegram, а на компьютере
через браузер: https://pomogaika.vddapp.ru/login, кнопка «Log in with Telegram».
Общей веб-панели без входа нет. Подробности в [docs/deploy.md](docs/deploy.md).

Добавить человека: в боте команда `/доступ` → «Пригласить» → переслать одноразовую ссылку.
Она живёт сутки. Собственника из списка убрать нельзя.

Демо-страница с кнопками показа («Парковка», «Скидка», «Калитка») убрана из раздачи,
файл лежит в `src/pomogaika/web/demo/index.html` — открывается из файловой системы,
но сервером не отдаётся.

## Запуск

Нужен Python 3.11+.

```powershell
cd $HOME\OneDrive\Desktop\Pomogaika
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:PYTHONPATH = "src"
python -m uvicorn pomogaika.web.app:app --host 127.0.0.1 --port 8000
```

Ручки `/api/*` требуют подпись Telegram. Чтобы дёргать их локально без мини-приложения,
добавьте в `.env` строку `TELEGRAM_AUTH_REQUIRED=false`.

Пока сервис работает на сервере, локально бота запускать нельзя: `getUpdates` эксклюзивный,
оба экземпляра получат `TelegramConflictError`.

Личный Авито через локальный Chrome, без бота и без аккаунта KaVa: [docs/avito-browser.md](docs/avito-browser.md).

## Telegram

Пошагово: [docs/telegram.md](docs/telegram.md). Кратко: токен от BotFather в `.env` как `TELEGRAM_BOT_TOKEN`, снова `.\run.ps1`, боту `/start` с вашего Premium-аккаунта. Гость пишет боту (или вам в личку, если подключите Business).

Проверка без UI:

```powershell
$env:PYTHONPATH = "src"
python -m pytest -q
```

Модель гостя — TokenRouter (`z-ai/glm-5.3-flash`). Ключ в `.env` как `TOKENROUTER_API_KEY`. Без ключа остаётся FAQ по словам. Скидки, отмены и коды двери по-прежнему решает код политик, не модель.

## Что это уже умеет

- База знаний KaVa из объявлений и переписок
- Политики как код: типовой confirm, деньги never, уборка auto
- Парсер писем Суточно / Авито / Островка / Яндекса
- Заезд и выезд в один день — не конфликт
- Журнал действий
- Telegram: копайлот в боте, Premium Business — ответ от вашего имени
